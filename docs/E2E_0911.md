| # | 확인 | 결과 |
|---|---|---|

| 2 | MEMBER `GET /activities?userId=1` (남의 id) | ✅ `403 NOT_YOUR_DATA` |
| 3 | MEMBER `GET /activities` (생략 = 내 것) | ✅ 200 |

| 9 | `POST /me/github/start` + `Origin: http://192.168.1.218:5173` | ✅ 200, 인가 URL 반환 (콜백 뒤 그 주소로 복귀) |
| 10 | 같은 요청 + `Origin: http://evil.example.com` | ✅ 403 — CORS 가 먼저 막는다 (OriginPolicy 까지 오지도 않음) |
| 11 | ADMIN `POST /admin/users/7/password-reset` → **같은 초 안에** 옛 토큰으로 `GET /me` | ✅ 401 (토큰의 `pwv` 클레임 ≠ 지금 버전) |
| 12 | 초기화 뒤 `9998`/`9998` 재로그인 | ✅ 200, `mustChangePassword=true` |
| 13 | `POST /me/password` → 응답의 새 토큰 200 · 변경 전 토큰 401 | ✅ |

> 11번에서 처음엔 iat(초 단위)와 변경 시각을 견줬더니 **로그인과 초기화가 같은 초에 들어오면 옛 토큰이 살았다.**
> 토큰에 비밀번호 버전(`pwv` = `password_changed_at` ms)을 적어 똑같은지 보는 것으로 바꿨다.

테스트 뒤 `9998` 은 초기 비밀번호(`9998`, 첫 로그인 시 변경)로 되돌려 두었고, 시험용 API Key 는 지웠다.
`9998` 의 오늘 VSCode 세션(id 5, 미푸시 커밋 1건 `abc1234`)은 **화면 확인용으로 남겨 두었다** — VSCode 내역 탭에서 보면 된다.
